# No AI slop

This name is an entry point and holds no rules of its own.

1. Read `~/.agents/skills/writing/core.md` if it is not already in your context.
2. Read `~/.agents/skills/writing/references/editing.md` and follow it: **Edit** by default, **Detect** when asked to audit, scan or flag without a rewrite.
3. If there is no draft, ask for it. This skill does not draft new prose; for that, use `writing`.
