# LinkedIn and X posts

A post is a story that teaches a method: a situation, what happened in it, and what the reader can now do. Ninad rejected a batch that had been compressed into terseness: "The X and LinkedIn posts are literally feeling like they're technical logs. I need stories, stories about things that people can do — basically mini tutorials people can follow."

## What a post is

- **A mini tutorial in prose.** Code and figures appear as evidence inside the narrative. `status["x"] == "HALTED" pins the regression` is a log line.
- **One outcome for the reader.** They finish able to do, avoid or detect something. "The author is competent" is not an outcome. Ninad's rejection of a draft set: "All the LinkedIn posts are about what I did and what I benefited."
- **Opened on the end of the story.** The first line shows the terminal moment plainly, and the body walks back to explain it. Nothing is withheld, so it is never a curiosity hook.
- **As long as the story needs.** A LinkedIn post runs long. An X thread carries the tutorial across posts. A brevity rule never justifies a post with no story.

## Positioning

| Platform | What it is for |

## Attention and authenticity

Ninad: "It's all a game of attention and authenticity." Attention is earned by the material: the strongest real finding goes first, and the surprising number sits where the reader meets it. Authenticity means a reader can tell a person did the work. Curiosity bait and manufactured tension buy attention by spending authenticity, so both fail.

Figures are in USD. When the work was done in rupees, state the conversion rate once so the number stays checkable.

## Check before delivery

1. Does the first line state the end of the story? If it sets the story up, move the ending forward.
2. Can you name the one outcome a stranger takes away? If you cannot, the post is about the author.
3. Would a person say each sentence aloud? If a line reads as release notes, rewrite it as what happened.
4. Is every gripping part true? If one is not, cut it.
