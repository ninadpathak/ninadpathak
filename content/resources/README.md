# Resources

This directory is reserved for reusable assets that are more substantial than an
article but are not interactive tools.

Use `/resources/` for:

- Templates
- Playbooks and checklists
- Ebooks
- Courses
- Downloadable reference material

Interactive generators, checkers, and software belong in `/projects/`. Editorial
guides and essays belong in `/articles/`.

The Resources page remains a draft and stays out of navigation until the first complete
asset passes review.
