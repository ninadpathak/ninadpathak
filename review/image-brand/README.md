# Image brand review

Sheets from `node tools/image-brand/review.mjs`. Before/after sheets screenshot the figure in its built article, then the same page with the v3 figure swapped in. Light and dark are separate sheets; the share card is light only. `v2-vs-v3-*` sheets compare the previous iteration with this one.

- `1-flowchart`: decision tree (internal-vs-external-docs)
- `2-anatomy`: annotated example (documentation-headings)
- `3-iframe-loop`: iframe replaced by a ring plate (agent-loop-anatomy)
- `4-og-card`: share card (agent-harnesses)
- `5-stack`: iframe replaced by layer slabs (llm-inference-optimization)
- `6-benchmark`: iframe replaced by tile bars (llm-token-budgets)

Guideline: `tools/image-brand/GUIDELINE.md`. Inventory and rollout: `tools/image-brand/INVENTORY.md`.
