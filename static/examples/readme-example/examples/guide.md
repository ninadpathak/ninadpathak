# Export service guide

This sample file exists so the commands in the README have something to read.

## Before you start

You need Node.js 24 and a terminal.

```bash
# check the version first
node --version
```

## Send a request

### Choose a format

The service accepts `csv` and `json`.

### Retry a lost response

Send the same idempotency key again.

## Troubleshooting

Compare the URL in your terminal with the one the service printed.
