## Result

The first generator-aware pass found one genuine syntax failure among 87
included samples from four supported documentation generators/pages. This is a
feasibility result, not an estimate: the five pages were selected to exercise
extractors, not sampled from the frozen project frame.

| Page | Generator | `<pre>` | Included | Raw syntax failures |
|---|---:|---:|---:|---:|
| Requests quickstart | Sphinx | 36 | 35 | 0 |
| HTTPX quickstart | MkDocs | 47 | 43 | **1** |
| Flask quickstart | Sphinx | 36 | 7 | 0 |
| Pydantic get-started | Starlight | 2 | 2 | 0 |
| Stripe API | unsupported custom renderer | 4 | 0 | excluded |

The HTTPX failure is not an intentional error example or an extractor artifact.
The [published quickstart](https://www.python-httpx.org/quickstart/) currently
serves this input in the multipart-upload section:

```python
with open('report.xls', 'rb') report_file:
```

It is missing `as` before `report_file`, so `ast.parse` fails. Two consecutive
fetches returned identical 79,175-byte responses with SHA-256
`3387d642a52ab4efb614bb79dd8b4f217dd30ebc6c3e37aede64ed60407f033d`, ETag
`"68c2ac65-13547"`, and `Last-Modified: Thu, 11 Sep 2025 11:03:01 GMT`.

The repository history supplies an unusually strong control: HTTPX
[fixed this exact syntax error](https://github.com/encode/httpx/commit/def4778d622e)
on 2025-10-16, one month after the live page's last-modified date, but the live
documentation still serves the pre-fix example in August 2026. Classification:
`broken`; secondary mechanism: `deployment-drift`.

This changes the study's useful taxonomy. A broken published sample can be:

1. broken in the current documentation source;
2. fixed in source but still broken on the deployed documentation site; or
3. valid in source but broken by extraction/rendering.

For every raw failure in the full run, the hand audit must compare the live block
against the current public source when a source link is available. That is a
small numerator-only extension and may produce a more useful docs-operations
finding than the aggregate rate.
