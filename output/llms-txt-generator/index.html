How to publish the generated file

  1. Download the file. Keep the filename exactly llms.txt.
  2. Place it at the website root. The public address should look like https://example.com/llms.txt.
  3. Check the response. The URL should return 200, serve readable plain text, and avoid redirects.
  4. Maintain it with the site. Update links when canonical URLs move, important pages change, or a section is retired.

What belongs in llms.txt

Include the pages that explain the product, help someone complete a task, or provide authoritative reference material. Use canonical URLs and descriptions that say what a reader will find.

Leave out duplicate routes, search results, account pages, thin tag archives, and URLs blocked from crawling. A shorter curated file is easier to maintain than an export of every sitemap URL.

What llms.txt does not do

The file does not grant or deny crawler access, replace structured data, or guarantee that an AI product will use the site. Keep robots.txt, the XML sitemap, canonical tags, and normal internal links working.

Frequently asked questions

What is an llms.txt file?

An llms.txt file is a proposed Markdown-formatted map that summarizes a website and links to its most useful pages for language-model systems.

Where should llms.txt be published?

Publish it at the root of the canonical website, such as https://example.com/llms.txt, and make sure the URL returns a plain-text 200 response.

Does llms.txt control AI crawlers?

No. Use robots.txt and access controls for crawler permissions. llms.txt is a discovery and context file.
